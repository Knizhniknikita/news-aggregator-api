## 📖 О проекте

Этот проект представляет собой бэкенд-сервис для агрегации новостных сводок. Приложение забирает актуальные записи из заданного RSS-канала, отфильтровывает дубликаты по уникальным ссылкам и сохраняет данные в локальную реляционную базу данных. 

Проект отлично подходит в качестве микросервиса для новостных ботов, дашбордов или контентных платформ.

### ✨ Ключевые возможности
* **Умный парсинг:** автоматическая загрузка новостей из любого RSS-источника с защитой от дубликатов на уровне БД (`UNIQUE` constraint).
* **Автоматическая инициализация:** база данных и необходимые директории создаются автоматически при первом запуске.
* **Безопасная модерация:** удаление записей защищено базовой HTTP-аутентификацией (`HTTP Basic Auth`) с поддержкой нескольких администраторов.
* **Интерактивная документация:** встроенный Swagger UI и ReDoc «из коробки».

## 🛠 Технологический стек

* **Backend:** Python 3.10+, FastAPI, Uvicorn
* **Парсинг и сеть:** Feedparser, urllib, Certifi (безопасная работа с SSL)
* **База данных:** SQLite3
* **Конфигурация:** Python-dotenv

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd news-aggregator-api
```

### 2. Настройка виртуального окружения
```bash
# Создание окружения
python -m venv venv

# Активация для Linux/macOS:
source venv/bin/activate

# Активация для Windows:
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Конфигурация (`.env`)
Создайте файл `.env` в корне проекта на основе примера `.env.example`:
```bash
cp .env.example .env
```

Заполните переменные в файле `.env`:

| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| `RSS_URL` | Ссылка на RSS-ленту (по умолчанию Google News) | `https://news.google.com/rss` |
| `ADMINS` | JSON-словарь с парами `логин: пароль` для доступа к удалению | `{"admin": "admin"}` |

### 5. Запуск приложения
```bash
uvicorn main:app --reload
```
После запуска интерактивная документация API будет доступна по адресу:  
👉 **Swagger UI:** [http://127.0.0](http://127.0.0)

## 📡 Эндпоинты API

| Метод | Эндпоинт | Доступ | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | Публичный | Запускает парсинг RSS и сохраняет новые статьи в БД |
| `GET` | `/news` | Публичный | Возвращает список всех сохраненных новостей (от новых к старым) |
| `DELETE` | `/news/{news_id}` | 🔒 Admin | Удаляет новость по её ID (требуется Basic Auth) |
